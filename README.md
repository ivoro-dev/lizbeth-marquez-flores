# Lizbeth Portfolio

## Start
```bash
npm install
npm run dev
```

## Building with Claude Code
Open this folder in VS Code, start Claude Code, then:

- `/next` builds the next task in `docs/BUILD-PLAN.md`. Run `/clear` after each one.
- `/fix <what's wrong>` applies your feedback with minimal changes.
- `/review` critiques the page and lists the top 10 problems (no code changes).

Rules for Claude live in `CLAUDE.md`. Design direction in `docs/DESIGN.md`, motion in `docs/MOTION.md`, image list in `docs/ASSETS.md`, brief in `docs/BRIEF.md`. All copy is in `src/content/`.
